## 📦 APK Download (GitHub Releases)

You can download the latest APK directly from GitHub Releases.

### Steps to upload APK:

1. Build release APK

```bash
flutter build apk --release
```

2. Go to your GitHub repository

3. Click **Releases → New Release**

4. Tag version (example):

```
v1.0.0
```

5. Release title:

```
RADHA COUNTER v1.0.0
```

6. Upload file:

```
build/app/outputs/flutter-apk/app-release.apk
```

7. Click **Publish Release**

Users can now download the APK without Play Store.
